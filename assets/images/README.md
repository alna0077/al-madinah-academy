# Approved image library

This directory contains the production-ready photography approved for the Al-Madinah Academy website.

## Core website images

- `arabic-magnets.webp` — Arabic foundations and learning materials
- `arabic-puzzle.webp` — child-friendly Arabic learning materials
- `books-dessert.webp` — books and community-study detail
- `hero-learning-room.webp` — primary academy learning-room image
- `learning-materials.webp` — prepared Qur’an and Arabic materials
- `study-room-real.webp` — real academy study-room environment
- `study-table-real.webp` — focused study-table detail
- `whiteboard-recitation.webp` — Qur’an recitation and whiteboard instruction

## News-only images

- `new-academy/SepCalendar.png` — September 2026 group-class calendar

News posters and calendars belong only in genuine News or Updates entries. They should not be reused as decorative photography elsewhere on the website.

## Excluded media

Do not add archived social-media exports, generated promotional artwork, old biography posters, unused videos, venue-revealing event media, or photographs with identifiable or deliberately obscured students to the production image library.

General website photography should come from the approved core pool. Review privacy, relevance, image quality, and site-wide repetition before adding or reusing an asset.
